# Changelog

All notable changes to Memo Cup are documented here.

## 0.1.0 — Initial release

- Add project-local SQLite memory storage with provenance, confidence, importance, and lifecycle states.
- Add deterministic lexical retrieval and bounded prompt-context formatting.
- Add MCP stdio tools for remember, recall, context, list, and soft-delete.
- Add authenticated loopback-only HTTP API.
- Add dependency-free Python and JavaScript clients.
- Add safe, idempotent project initialization and MCP configuration merging.
- Add JSON export/import with record IDs and lifecycle relationships preserved.
